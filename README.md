# graduation-project

项目根目录已按“代码 / 文档 / 报告 / 工具”做了整理，建议以后按下面的分工放文件：

- `ecommerce-autotest/`：自动化测试主项目代码
- `docs/`：项目说明、测试文档、阶段记录
- `reports/`：测试报告、截图、调试输出
- `tools/`：临时调试脚本、小工具
- `chromedriver/`：浏览器驱动相关文件

- [测试说明](docs/测试说明.md)
- [项目进度续接摘要](docs/notes/项目进度续接摘要.md)
